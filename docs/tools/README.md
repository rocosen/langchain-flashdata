# Google and YouTube task guides for LangChain

One source-specific Python tool per task, sharing the `langchain-flashdata` package. Installing the package is free; FlashData queries are paid. These are our public usage guides, not a claim that LangChain has accepted 15 directory entries.

| Task | Python class | Guide |
| --- | --- | --- |
| Find citable web results for an agent | `FlashDataGoogleSearch` | [Google Search](https://github.com/flashdata-dev/langchain-flashdata/blob/main/docs/tools/google_search.md) |
| Build a topic briefing with publisher links | `FlashDataGoogleNews` | [Google News](https://github.com/flashdata-dev/langchain-flashdata/blob/main/docs/tools/google_news.md) |
| Find image candidates with source pages | `FlashDataGoogleImages` | [Google Images](https://github.com/flashdata-dev/langchain-flashdata/blob/main/docs/tools/google_images.md) |
| Compare merchant result snapshots | `FlashDataGoogleShopping` | [Google Shopping](https://github.com/flashdata-dev/langchain-flashdata/blob/main/docs/tools/google_shopping.md) |
| Discover video pages across websites | `FlashDataGoogleVideos` | [Google Video Search](https://github.com/flashdata-dev/langchain-flashdata/blob/main/docs/tools/google_videos.md) |
| Find local business candidates | `FlashDataGooglePlaces` | [Google Places](https://github.com/flashdata-dev/langchain-flashdata/blob/main/docs/tools/google_places.md) |
| Shortlist videos by topic | `FlashDataYouTubeSearch` | [YouTube Search](https://github.com/flashdata-dev/langchain-flashdata/blob/main/docs/tools/youtube_search.md) |
| Collect a larger video discovery set | `FlashDataYouTubeExtendedSearch` | [YouTube Extended Search](https://github.com/flashdata-dev/langchain-flashdata/blob/main/docs/tools/youtube_search_extended.md) |
| Inspect a video before deeper processing | `FlashDataYouTubeMetadata` | [YouTube Video Metadata](https://github.com/flashdata-dev/langchain-flashdata/blob/main/docs/tools/youtube_metadata.md) |
| Build timestamped transcript evidence | `FlashDataYouTubeTranscript` | [YouTube Transcript](https://github.com/flashdata-dev/langchain-flashdata/blob/main/docs/tools/youtube_transcript.md) |
| Read the uploader-provided caption track | `FlashDataYouTubeCaptions` | [YouTube Captions](https://github.com/flashdata-dev/langchain-flashdata/blob/main/docs/tools/youtube_captions.md) |
| Inspect the Creative Commons label | `FlashDataYouTubeTrainability` | [YouTube License Metadata](https://github.com/flashdata-dev/langchain-flashdata/blob/main/docs/tools/youtube_trainability.md) |
| Snapshot a channel and recent uploads | `FlashDataYouTubeChannel` | [YouTube Channel Data](https://github.com/flashdata-dev/langchain-flashdata/blob/main/docs/tools/youtube_channel.md) |
| Explore phrasing before video search | `FlashDataYouTubeSuggestions` | [YouTube Autocomplete](https://github.com/flashdata-dev/langchain-flashdata/blob/main/docs/tools/youtube_suggestions.md) |
| Deliver video or audio to customer storage | `FlashDataYouTubeDownload` | [YouTube Download](https://github.com/flashdata-dev/langchain-flashdata/blob/main/docs/tools/youtube_download.md) |
