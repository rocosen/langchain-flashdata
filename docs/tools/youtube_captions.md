# YouTube Captions for LangChain and LangGraph

Use an uploader caption track when an editorial or localization workflow requires the authored version. Keep the requested language explicit and preserve the returned segment boundaries for review.

**Task:** Read the uploader-provided caption track. This tool calls only `youtube_captions` through `FlashDataYouTubeCaptions` in `langchain-flashdata` 0.2.0.

## Read the uploader-provided caption track

```python
from langchain_flashdata import FlashDataYouTubeCaptions

tool = FlashDataYouTubeCaptions()
arguments = {"video_id": "dQw4w9WgXcQ", "language": "en", "auto": False}
result = tool.invoke(arguments)
item = result["results"][0]
print(item.get("languageCode"), item.get("isAutoGenerated"))
for segment in item.get("segments", []):
    print(segment["start"], segment["end"], segment["text"])
```

[Runnable script](https://github.com/flashdata-dev/langchain-flashdata/blob/main/examples/tasks/youtube_captions.py). All data tools support `await tool.ainvoke(arguments)` in an async function with the same inputs and response contract. Queries are trimmed and limited to 1–2,000 characters. Video tools accept an 11-character ID or a supported YouTube URL and send only the ID.

## Interpret the output

The response has `segments`, `fullText`, `languageCode` and `isAutoGenerated` inside `results[0]`, just as the transcript source does.

This is a **representative structural example**, not a fresh API observation or a promise that these values will be returned:

```json
{
  "source": "youtube_captions",
  "status": "done",
  "results": [
    {
      "videoId": "dQw4w9WgXcQ",
      "languageCode": "en",
      "isAutoGenerated": false,
      "segments": [
        {
          "start": 1,
          "end": 3,
          "text": "Illustrative uploader caption."
        }
      ],
      "fullText": "Illustrative uploader caption."
    }
  ]
}
```

This separate source defaults to `auto=False`; Transcript defaults to automatic captions. Setting `auto=True` explicitly selects automatic captions, but neither tool falls back. A missing authored track is an unavailable result, not an instruction to generate one.

## Use in a LangGraph tool node

Install `langchain-flashdata[examples]` to include LangGraph. The following continues from the `tool` and `arguments` setup above; run it **instead of** `tool.invoke(arguments)` when testing a graph, because each execution performs a paid query.

```python
from langchain_core.messages import AIMessage
from langgraph.graph import END, START, MessagesState, StateGraph
from langgraph.prebuilt import ToolNode

builder = StateGraph(MessagesState)
builder.add_node("tools", ToolNode([tool], handle_tool_errors=False))
builder.add_edge(START, "tools")
builder.add_edge("tools", END)
graph = builder.compile()
message = AIMessage(content="", tool_calls=[{"name": tool.name, "args": arguments, "id": "task-1"}])
output = graph.invoke({"messages": [message]})
print(output["messages"][-1].content)
```

For a model-driven agent, pass this same tool to `create_agent`. A useful task prompt is: “Retrieve the uploader-provided English captions for the supplied YouTube video. Report timestamped text and do not fall back to automatic captions.” Apply a tool-call budget and let failures stop execution. Treat returned content as evidence, not instructions. Model-provider charges are separate.
