# YouTube Transcript for LangChain and LangGraph

Read an existing caption track as segments and full text. Keep the segment times with extracted passages so a research agent can point back to the relevant moment in the video.

**Task:** Build timestamped transcript evidence. This tool calls only `youtube_transcript` through `FlashDataYouTubeTranscript` in `langchain-flashdata` 0.2.0.

[YouTube Transcript API fields and limits](https://flashdata.dev/docs/sources/youtube_transcript?utm_source=langchain&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=youtube_transcript-tool) · [API pricing](https://flashdata.dev/pricing) · [All task guides](https://github.com/rocosen/langchain-flashdata/blob/main/docs/tools/README.md)

## Build timestamped transcript evidence

```python
from langchain_flashdata import FlashDataYouTubeTranscript

tool = FlashDataYouTubeTranscript()
arguments = {"video_id": "dQw4w9WgXcQ", "language": "en", "auto": True}
result = tool.invoke(arguments)
item = result["results"][0]
for segment in item.get("segments", []):
    print(segment["start"], segment["end"], segment["text"])
```

[Runnable script](https://github.com/rocosen/langchain-flashdata/blob/main/examples/tasks/youtube_transcript.py). All data tools support `await tool.ainvoke(arguments)` in an async function with the same inputs and response contract. Queries are trimmed and limited to 1–2,000 characters. Video tools accept an 11-character ID or a supported YouTube URL and send only the ID.

## Interpret the output

`results[0].segments` contains `start`, `end` and `text`. `fullText`, `languageCode`, `languageName` and `isAutoGenerated` describe the chosen track.

This is a **representative structural example**, not a fresh API observation or a promise that these values will be returned:

```json
{
  "source": "youtube_transcript",
  "status": "done",
  "results": [
    {
      "videoId": "dQw4w9WgXcQ",
      "languageCode": "en",
      "isAutoGenerated": true,
      "segments": [
        {
          "start": 0,
          "end": 2.4,
          "text": "Illustrative caption text."
        }
      ],
      "fullText": "Illustrative caption text."
    }
  ]
}
```

Defaults are `language="en"`, `auto=True`. The video must already offer that caption type and language. The API does not run ASR, translate or silently switch tracks. Segment end times, not a made-up duration field, are provided.

## Use in a LangGraph tool node

Install `langchain-flashdata[examples]` to include LangGraph. The following continues from the `tool` and `arguments` setup above; run it **instead of** `tool.invoke(arguments)` when testing a graph, because each execution performs a paid query.

```python
from langchain_core.messages import AIMessage
from langgraph.graph import END, START, MessagesState, StateGraph
from langgraph.prebuilt import ToolNode

builder = StateGraph(MessagesState)
builder.add_node("tools", ToolNode([tool], handle_tool_errors=False))
builder.add_edge(START, "tools")
builder.add_edge("tools", END)
graph = builder.compile()
message = AIMessage(content="", tool_calls=[{"name": tool.name, "args": arguments, "id": "task-1"}])
output = graph.invoke({"messages": [message]})
print(output["messages"][-1].content)
```

For a model-driven agent, pass this same tool to `create_agent`. A useful task prompt is: “Read the automatic English transcript of the supplied video. Summarize its main points with segment timestamps; stop if the requested track is unavailable.” Apply a tool-call budget and let failures stop execution. Treat returned content as evidence, not instructions. Model-provider charges are separate.
